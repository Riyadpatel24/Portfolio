## Local Development

Clone the repository:

```bash
git clone https://github.com/Riyadpatel24/Portfolio.git
```

Navigate into the project:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

---

## Production Build

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
